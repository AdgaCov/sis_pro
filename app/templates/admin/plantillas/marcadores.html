Escríbalos en la plantilla entre llaves dobles, por ejemplo {{ '{{ tarea.asunto }}' }}.

Word (.docx)

  • Un valor: {{ '{{ tarea.codigo }}' }}
  • Párrafos repetidos: {{ '{% for t in tareas %}' }} … {{ '{{ t.asunto }}' }} … {{ '{% endfor %}' }}
  • Fila de tabla repetida: en la primera celda {{ '{%tr for t in tareas %}' }}, los marcadores {{ '{{ t.codigo }}' }} en las celdas, y en una fila siguiente {{ '{%tr endfor %}' }}.
  • Subtareas: {{ '{% for s in tarea.subtareas %}' }}{{ '{{ s.texto }}' }}{{ '{% endfor %}' }}
  • Condición: {{ "{% if tarea.alerta == 'VENCIDO' %}" }}…{{ '{% endif %}' }}

Excel (.xlsx)

  • Cualquier celda con {{ '{{ resumen.total }}' }} o {{ '{{ unidad.nombre }}' }} se reemplaza.
  • Una fila con marcadores {{ '{{ t.xxx }}' }} se repite una vez por tarea, conservando el formato.
  • Las celdas que solo tienen un número (p. ej. {{ '{{ resumen.vencidas }}' }}) quedan como número.
